# MonthPin

매달 나가는 고정비와 결제수단을 관리하는 Expo / React Native 앱입니다.

## 아이폰에서 실행하기

프로젝트 폴더에서 실행합니다. 이미 실행 중인 Expo 터미널은 Ctrl+C로 종료하고 다시 시작해 주세요.

```sh
npx expo start --go --clear
```

아이폰과 컴퓨터를 같은 Wi-Fi에 연결한 뒤 카메라로 QR 코드를 스캔하고 Expo Go로 엽니다.

1. **결제수단**에서 통장 또는 카드를 등록합니다.
2. **고정비**에서 이름, 월 금액, 결제일과 결제수단을 입력합니다.
3. **홈**에서 월 합계와 다가오는 결제 일정을 확인합니다.

항목을 누르면 상세 정보를 볼 수 있고 수정·삭제할 수 있습니다. 처음 실행하면 빈 목록으로 시작합니다.

## 현재 구현 범위

- 홈 / 고정비 / 결제수단 / 설정 하단 탭
- 고정비 등록·수정·삭제와 선택적인 결제수단 연결
- 은행·통장 별명, 카드사·카드 이름, 카드 대금 출금 통장·출금일
- 카드 대금을 내는 통장 기준의 고정비 합계와 중복 없는 전체 합계
- 29~31일이 없는 달은 월말로 표시하는 예상 결제 일정
- SQLite 기기 저장: 앱 재시작 후에도 유지

서버, 계정 로그인, 자동 금융 연동, 알림, 별도 백업, 기기 간 동기화는 구현하지 않았습니다. 앱 삭제나 앱 데이터 초기화 시 데이터가 사라질 수 있습니다. Expo Go에서 저장한 데이터는 해당 개발 프로젝트의 데이터이며, 추후 스토어 앱으로 자동 이전되지는 않습니다.

현재 저장 방식은 iOS·Android를 대상으로 합니다. SQLite의 웹 실행 설정은 별도로 구성하지 않았습니다.

## 파일 구조

앱의 시작점은 `expo-router/entry`입니다. 예전 `App.tsx` 대신 아래 화면 파일을 수정합니다.

- `src/app/(tabs)/`: 홈, 고정비, 결제수단, 설정 화면과 하단 탭
- `src/app/_layout.tsx`: 앱 공통 설정과 데이터 저장 초기화
- `src/components/`: 공통 화면 구성과 입력 폼
- `src/data/`: 데이터 모델과 SQLite 읽기·쓰기
- `src/hooks/`: 화면에 데이터를 공유하는 상태 관리
- `src/utils/`: 합계, 날짜 계산, 입력 검증

나중에 백엔드를 추가할 때는 화면과 분리된 데이터 읽기·쓰기 부분부터 변경할 수 있습니다.


테스트는 Node.js 22.13 이상에서 실행합니다. 실제 SQLite로 저장·수정·삭제, 재접속 후 유지, 연결 해제와 합계를 검증하고 월말·윤년 결제 일정을 확인합니다. 기기 UI, 키보드, 실제 Expo Go 실행은 아이폰·안드로이드에서 추가 확인해야 합니다.
